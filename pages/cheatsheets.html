Gitコマンドチートシート

📦 基本操作

コマンド 説明
git init 新しいGitリポジトリを作成
git clone <URL> リモートリポジトリをクローン
git status 現在の状態を確認
git add . すべての変更をステージング
git add <ファイル名> 特定のファイルをステージング
git commit -m "メッセージ" 変更をコミット
git push origin main リモートにプッシュ（mainブランチ）
git pull origin main リモートから最新を取得

🌿 ブランチ操作

コマンド 説明
git branch ブランチ一覧を表示
git branch <ブランチ名> 新しいブランチを作成
git checkout <ブランチ名> ブランチを切り替え
git checkout -b <ブランチ名> ブランチを作成して切り替え
git merge <ブランチ名> 指定したブランチを現在のブランチにマージ
git branch -d <ブランチ名> ブランチを削除

🔍 確認・履歴

コマンド 説明
git log コミット履歴を表示
git log --oneline コミット履歴を1行で表示
git diff 変更内容を表示
git diff --staged ステージング済みの変更を表示
git show <コミットID> 特定のコミットの詳細を表示

⚠️ 緊急時のコマンド

コマンド 説明
git reset HEAD <ファイル名> ステージングを取り消し
git checkout -- <ファイル名> ファイルの変更を取り消し
git reset --soft HEAD~1 直前のコミットを取り消し（変更は保持）
git reset --hard HEAD~1 直前のコミットを取り消し（変更も削除）
git stash 一時的に変更を退避
git stash pop 退避した変更を復元
git revert <コミットID> 特定のコミットを打ち消すコミットを作成

マークダウン記法チートシート

📝 基本構文

記法 説明 結果
# 見出し1 最大の見出し 見出し1
## 見出し2 2番目の見出し 見出し2
**太字** 太字にする 太字
*斜体* 斜体にする 斜体
`コード` インラインコード コード
[リンク](URL) リンクを作成 リンク
![画像](URL) 画像を挿入 画像が表示される

📋 リストと引用

記法 説明
- 項目 箇条書きリスト
1. 項目 番号付きリスト
> 引用 引用ブロック
--- 水平線

💻 コードブロック

```javascript
function hello() {
  console.log('Hello!');
}
```

3つのバッククォート（```）で囲むと、コードブロックになります。言語名を指定するとシンタックスハイライトされます。

📐 Flexboxの基本

/* コンテナに指定 */
.container {
  display: flex;
  justify-content: center;  /* 横方向の配置 */
  align-items: center;      /* 縦方向の配置 */
  gap: 20px;                /* 要素間の間隔 */
}

justify-content の値： flex-start, center, flex-end, space-between, space-around

align-items の値： flex-start, center, flex-end, stretch

チートシート活用のコツ

  • 最初は全部覚えなくてOK： 必要な時に見返すためのリファレンスとして使いましょう
  • よく使うものから覚える： 毎日使うコマンドは自然と覚えていきます
  • カスタマイズする： 自分がよく使うコマンドをメモに追加していきましょう
  • 印刷して貼る： デスクに貼っておくと、調べる時間が短縮されます
