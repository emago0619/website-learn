このページについて

「Claude Codeって何？」「CursorとどうClaude Codeを違うの？」「どうやってインストールするの？」 そんな疑問に、初心者のタロウさんとベテランエンジニアの先輩の対話を通じて答えていきます。

登場人物：
タロウ：Cursorを使い始めた初心者。もっと効率的に開発したい
先輩：Claude Codeを日常的に使うベテランエンジニア
2026年最新情報： このページはClaude Code v2.1.0（2025年末リリース）に基づいています。 スキル、フック、IDE連携など最新機能をカバーしています！

第1話：「Claude Codeって何？」

タロウ：先輩、Claude Codeってよく聞くんですけど、Cursorとは何が違うんですか？

先輩：いい質問！簡単に言うと、こんな違いがあるんだ：

🔥 2026年の定番：「Cursor + Claude Code」の組み合わせ
「CursorはAIがあなたを速くする」
「Claude CodeはAIがあなたの代わりに仕事をする」
特徴 Cursor Claude Code
操作方法 GUI（グラフィカル） CLI（ターミナル）
得意なこと 日常的な編集、探索 大規模リファクタ、自動化
作業スタイル 対話的・リアルタイム タスクを任せて自律実行
コードベース理解 開いているファイル中心 プロジェクト全体をスキャン

タロウ：なるほど！じゃあ使い分けるってこと？

先輩：そうそう！2026年は「両方使う」のがベストプラクティスなんだ。 日常的な編集はCursor、重い作業はClaude Codeって感じでね。

第2話：「インストールしてみよう」

タロウ：早速使ってみたいです！どうやってインストールするんですか？

先輩：超簡単だよ！npmかHomebrewで一発！

インストール方法

方法1: npm（推奨）

# Node.jsがインストールされていれば
npm install -g @anthropic-ai/claude-code

方法2: Homebrew（Mac）

brew install claude-code

方法3: Windows Package Manager

winget install Anthropic.ClaudeCode

初期設定

# インストール確認
claude --version

# Anthropicアカウントでログイン
claude login

# プロジェクトで初期化
cd your-project
claude

タロウ：え、これだけ？

先輩：うん！Claude Pro（月$20）があれば、ログインするだけで使えるよ。 API従量課金でも使えるけど、Proの方がコスパいいね。

第3話：「基本的な使い方」

タロウ：インストールできました！どう使うんですか？

先輩：基本は「自然言語で指示する」だけ！

基本コマンド

# 対話モードを開始
claude

# 直接指示を出す
claude "このバグを修正して"
claude "認証機能を追加して"
claude "テストを書いて"

# スラッシュコマンド（v2.1.0新機能）
claude /commit    # コミットメッセージ自動生成
claude /review    # コードレビュー
claude /help      # ヘルプ表示

よく使うパターン

1. バグ修正

claude "ログイン時にエラーが出る。調査して修正して"

2. 機能追加

claude "ユーザープロフィールに画像アップロード機能を追加して"

3. リファクタリング

claude "この認証ロジックを別ファイルに分離して整理して"

4. ドキュメント生成

claude "このプロジェクトのREADMEを書いて"

5. テスト作成

claude "このAPIの単体テストを書いて"

タロウ：自然言語で指示するだけで、勝手にファイルを編集してくれるんですか！？

先輩：そう！しかもGitと連携してるから、変更内容をコミットまで自動でやってくれるんだ。

第4話：「IDE連携」

タロウ：ターミナルだけじゃなくて、IDEでも使えるんですか？

先輩：v2.1.0からネイティブ拡張が出たんだ！

対応IDE

  • VS Code：公式拡張機能
  • Cursor：Claude Codeと併用可能
  • Windsurf：ネイティブ対応
  • JetBrains系：IntelliJ、PyCharm、WebStormなど

インストール方法（VS Code）

# VS Code拡張機能マーケットプレイスから
# "Claude Code" で検索してインストール

# または
code --install-extension anthropic.claude-code

ベストプラクティス：Cursor + Claude Code

おすすめワークフロー：
  1. Cursorで日常的なコード編集・探索
  2. 大きな変更が必要になったらClaude Codeにタスクを投げる
  3. Claude Codeが作業している間、Cursorで別の作業を継続
  4. Claude Codeの成果物を確認・微調整

タロウ：並行して作業できるのがいいですね！

先輩：そうなんだ！Claude Codeは自律的に動くから、重い作業を任せている間に別のことができるんだよ。

第5話：「v2.1.0の新機能」

タロウ：最新バージョンの新機能を教えてください！

先輩：v2.1.0は大型アップデートだったよ！主な新機能を紹介するね。

1. スキル機能

カスタムワークフローを定義できる。よく使う作業パターンを保存しておける。

# スキルの例（~/.claude/skills/に保存）
# my-commit-style.yaml
name: my-commit-style
description: 日本語でコミットメッセージを書く
instructions: |
  コミットメッセージは日本語で書いてください。
  形式: feat: 機能追加の説明

2. フック機能

ツール実行前後にカスタムロジックを挿入できる。

# PreToolUse: ツール実行前
# PostToolUse: ツール実行後
# Stop: 処理終了時

3. Claude in Chrome

ブラウザを直接操作できる！WebスクレイピングやE2Eテストに便利。

claude "Chrome拡張をインストールして、
       このWebサイトのフォームをテストして"

4. モバイル対応

スマホからクラウドVMに接続して開発できる。通勤中にコードレビュー！

5. Tool Search Tool

必要なツールを動的に発見。大量のMCPツールがあっても効率的に動作。

タロウ：ブラウザまで操作できるんですか！すごい！

先輩：そう！E2Eテストの自動化とか、データ収集とか、かなり便利だよ。

第6話：「実践例」

タロウ：実際にどんな場面で使うんですか？

先輩：いくつか実践例を見せるね！

例1: ドキュメント自動生成

       OpenAPI形式でdocs/api.yamlに出力して"

例3: 大規模リファクタリング

例4: セキュリティ監査

例5: 依存関係の更新

claude "package.jsonの依存関係を最新バージョンに更新して。
       破壊的変更があれば対応して、テストを通して"

タロウ：こんなに複雑なタスクも任せられるんですね！

先輩：50万行以上のコードベースでも約75%の成功率って言われてるよ。 もちろん複雑なタスクは途中で確認を求められることもあるけどね。

第7話：「他のCLIツールとの比較」

タロウ：Aiderとか、他のCLIツールもありますよね？違いは？

先輩：いい視点！主要なツールを比較してみよう。

ツール 特徴 料金 向いている人
Claude Code Anthropic公式、IDE連携、スキル機能 Claude Pro $20/月 メイン利用、大規模開発
Aider OSS、多モデル対応、ローカルLLM可 API従量課金 カスタマイズ好き、コスト重視
Gemini CLI Google製、1日1000リクエスト無料 無料枠大 無料で試したい人
Antigravity 軽量、シンプル API従量課金 シンプルさ重視
先輩のおすすめ：
メインはClaude Code、コスト節約したい時はAider + ローカルLLM、 無料で試すならGemini CLIって使い分けるといいよ！

タロウ：なるほど、用途で使い分けるんですね！

第8話：「トラブルシューティング」

タロウ：うまくいかない時はどうすればいいですか？

先輩：よくあるトラブルと解決法を教えるね！

Q1: ログインできない

# 再ログイン
claude logout
claude login

# ブラウザでAnthropicアカウントを確認
# Claude Proが有効か確認

Q2: コンテキストが大きすぎるエラー

# .claudeignoreファイルを作成
echo "node_modules/" >> .claudeignore
echo "dist/" >> .claudeignore
echo "*.log" >> .claudeignore

Q3: 変更が意図と違う

# Gitで元に戻す
git checkout .

# より具体的に指示を出し直す
claude "修正して"
↓
claude "src/auth/login.tsの42行目のnullチェックを追加して"

Q4: 処理が遅い

  • コードベースが大きすぎる場合は.claudeignoreで除外
  • タスクを小さく分割して依頼
  • ネットワーク環境を確認

Q5: エラーメッセージが出た

# バージョン確認
claude --version

# アップデート
npm update -g @anthropic-ai/claude-code

# ヘルプ確認
claude /help

タロウ：これで困っても大丈夫そうです！

先輩：あと、公式のGitHubリポジトリでIssueを報告することもできるよ。 コミュニティも活発だから、困ったら聞いてみるといいね。

まとめ：これだけは覚えよう！

  1. Claude CodeはターミナルベースのAIコーディングツール

  2. Cursorとの使い分けが2026年のベストプラクティス
    • Cursor：日常的な編集、探索
    • Claude Code：大規模リファクタ、自動化
  3. v2.1.0の新機能をフル活用

  4. インストールは簡単
    • npm install -g @anthropic-ai/claude-code
